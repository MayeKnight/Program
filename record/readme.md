# record 技术文档记录

## 一. 前言

`record` 文件夹用于收录技术文档，即在学习过程中的“日志”记录文件（这里称为 `basic_code` 文件），详见当前目录下的 `tech_record` 文件夹。

`basic_code` 文件有两个主要用途：

- 一是作为个人知识框架使用，用于在未来可能的开发过程中作为锚点进行查询、学习和强化。
- 二是考虑到 RoboMaster 等相关经历，或可作为参考教程和可行、可借鉴的路线给新人学习。（欢迎后续补充扩充，例如增添更多 `basic_code` 学习记录内容）

对于 `yolov8_basic_code`，该文件描述了从创建 YOLOv8 环境、自行构建数据集、LabelImg 标注、构建数据集描述文件，以及进行 YOLOv8 迁移训练的完整过程，并包含部分相关疑难点（如 IoU、mAP 等），方便后续的消融实验和量化模型等内容的学习。  
如用于 RoboMaster 的学习，可以将构建数据集的视频文件换成装甲板视频（可自行录制）。  
若完成学习，最终将会收获一份从零到一的基于 `yolov8n.pt` 的识别装甲板的模型。

对于 `pytorch_basic_code`，该文件记录了学习 PyTorch 基本架构的过程，包含了如何自行构建一个神经网络等内容。  
对于 RoboMaster 的学习，该 `basic_code` 有助于深入理解 YOLOv8，如 `dataloader()` 等加载数据的过程。

## 三. 部分成果展示

本节主要结合近期的毕设环节开展“基于 YOLO 算法的细胞识别及移动路径规划”。

经过收集数据集，通过 LabelImg 对 8001 张图片进行标注构建数据集，构建数据集描述文件，并通过 `yolov8n.pt` 预训练模型，在自定义细胞数据集上做 50 个 epoch 迁移训练（`batch=16`，输入 `640×640`，开启 Mosaic 等数据增强），得到初步的细胞识别模型，保存到了 `train12` 目录下。

所得结果详见当前 `record` 目录下的 `record/train12`，包含：

- [P-R 图](./record/train12/BoxPR_curve.png)
- [训练时的 loss 曲线](./record/train12/results.png)
- [最终验证集的检测结果](./record/train12/val_batch2_labels.jpg)

等等内容。

在训练过程中该细胞识别模型 **mAP50** 达到了 **0.926**，**mAP50-95** 达到了 **0.594**，说明模型几乎能检测出数据集中所有目标，且大致位置正确，但精细定位能力尚需改善（预测框不够紧贴）。  
虽然对于许多实际应用（如人流计数、车辆检测、缺陷存在性判断等），`mAP50=0.926` 依然足够，但对于需要精确定位的任务（如机器人抓取、医学图像病灶分割等），`mAP50-95=0.594` 偏低，尚需优化。
